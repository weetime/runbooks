# 候选矩阵：冻结后才执行

遵循`BENCHMARK_POLICY.md`；本文件为候选，B300资源/最终配方和G3预算未冻结。

## 门禁

- G0：全权重逐文件SHA256、index完整性、编码/分词器离线加载、统一数据1,042项校验、镜像远端digest。
- G1：B300实际型号/CC/卡数/互联、全部rank存活、日志最终并行、KV池、图、DSpark、内存与理论容量。
- G2：两臂短答与token对账、视觉/工具/长检索各一条。HTTP流/非流门禁只适用于真实HTTP适配层。
  DeepInfer原生接口通过不能记在线协议通过。原生结构化输出/PPL按官方样例验收。
- G3：8K/512单流，8请求×3轮；DeepInfer必须确认单协调器请求实际映射和通信。
  decode P50<15tok/s（无参照）、退化>20%或三轮极差>10%即停。普通batch模式无逐请求计时；--g3提供原生host chunk诊断，须现场验证接口、原始输出与token对账后审核，不当HTTP成绩。
- G4a/G4b：真实Agent/CC分别核验；当前在线适配不支持时记not_run，记录原因，不伪造HTTP结果。
- G5：本轮单机不适用；跨机必须新登记资源与通信门禁。

## 快速、标准与增强

| 场景 | 快速档 | 标准档 | 本次边界 |
|---|---|---|---|
| 固定1K/256 | C1，8请求 | C1/C8各128条 | 原生批次B1/B8另表；不冒充C |
| 固定8K/512 | C1复用G3；C8 32条 | C1/C8各128条；按停止线C16→32→48→64→80 | 每档不循环样本 |
| 固定32K/512 | C1 16条 | C1/C8各128条 | 主问题不要求32K高并发 |
| 固定128K/512 | 检索探针另列 | C1 128条，窗口/KV允许才选 | 不能由支持1M推断装得下 |
| 8K/2048 | 标准增量 | C1 128条 | 输出token含reasoning |
| ShareGPT自然EOS | C1/C8各32条 | C1/C8/C16各128条 | 历史固定源，预算16384候选；先预算预检 |
| RAG自然EOS | C1 8条 | C1/C8各128条 | 核验文档独立性，预算4096候选 |
| 真实消息Agent | ≥4完整会话 | C1/C8，冻结会话/轮次 | 当前缺DeepInfer在线服务：not_run |

| 长检索128K/512K | 各1条 | 各≥8条，近1M按窗口选择 | 首次请求/未预热；验证命中才称冷/热 |
| 开环泊松 | 无 | 低/近拐点/过载各≥5min | 无在线入口或有效C1/拐点则not_run |

主对比先完成共同支持的原生离线B1/B8/B16，先快速缩样再标准128。
批大小只能解释批处理吞吐，不应用闭环扩档停止线冒充容量验收；资源/错误/质量异常照停。
官方prefill/decode sweep独立列诊断，不和端到端原生生成同表。
若在线适配后续获授权，以上C/RPS矩阵再按AIPerf真实发压，先补所有在线门禁。

标准档单次起服仅为观测。正式对比采用A→B→A→B→A→B，至少三次独立起服；
关键点预登记为8K/32K B1、共同扫描到的最高有效batch及结论依赖点（在线时对应C1/拐点）。
不同启动噪声分别报告，差异小于噪声底写不可分辨。

## 指标与停止线

原生主表：实际ISL/OSL、n、B、batch wall time、实际输出tok/s、tok/s/卡、自然完成/触顶/未知、
质量复核和配方指纹；普通batch的HTTP TTFT/TPOT/goodput写not_measured；G3原生host chunk诊断另表。
在线主表按纪律完整记录TTFT/TPOT/E2E、goodput、命中、排队、抢占及DSpark drafted/accepted/steps。

在线停止线：吞吐增长<10%、TPOT P95>100ms、TTFT P95>10×同形状C1、错误率>1%、
排队/抢占持续增长、资源不允许，任一即停。小样本分位数不用于扩档；P95需要≥128独立有效请求。
原生数据缺逐请求TPOT时不借用在线停止线推断容量；只报告已完成batch范围。
每批前后自然输出哨兵；异常输出保留全量并人工复核，确认无效后从正式有效统计剔除并同时报全量观测。
自然预算触顶单独记录；工具参数截断则停止该会话后续派发。普通文本length不自动判传输失败。
